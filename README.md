Este repositorio contiene un proyecto de análisis de datos orientado al estudio comparado del Producto Interno Bruto (PIB) y su relación con variables macroeconómicas, demográficas y sociales para distintos países y períodos. El foco del trabajo está en la preparación, exploración y transformación de los datos, con el objetivo de construir una base adecuada para modelos de clasificación posteriores.
